# Tic Tac Toe Game

## Project Overview
This project is mainly about understanding and building game logic using Python.  
Tic Tac Toe is used as a simple example to understand turns, rules, input, conditions, and win/draw checking.

Player 1 uses **X** and Player 2 uses **O**.

The game checks whether a player has won or whether the game is a draw.

## Features
- Two-player game
- Simple 3 × 3 board
- Checks for a winner
- Checks for a draw
- Does not allow an already used position
- Checks invalid input
- Easy to play from the terminal

## Technologies Used
- Python 3
- VS Code or any Python editor
- Terminal / Command Prompt

## Project Files
- `tic_tac_toe.py` - Main Python program
- `README.md` - Project information
- `statement.md` - Problem statement and project scope

## How to Install and Run

### 1. Install Python
Install Python 3 on your computer.

### 2. Open the project
Open the project folder in VS Code.

### 3. Run the program
Open the terminal and type:

```bash
python tic_tac_toe.py
```

If your computer uses `python3`, use:

```bash
python3 tic_tac_toe.py
```

## How to Play
1. Player X or O starts the game.
2. Enter a position from 1 to 9.
3. Player O then gets a turn.
4. Continue until a player wins or the board is full.
5. Three matching symbols in a row, column, or diagonal means a win.

## Position Guide

```text
1 | 2 | 3
--+---+--
4 | 5 | 6
--+---+--
7 | 8 | 9
```

## Testing
The program can be tested with:
- Valid positions from 1 to 9
- A position that is already taken
- A value outside 1 to 9
- Letters or other non-number input
- A winning game
- A draw game

## Result
The game runs in the terminal and displays the board after every turn.
